# PHASE 1 — BRAND & CONTENT MIGRATION

## Objective

The React migration has already been completed successfully.

The project architecture is stable.

GSAP animations are working.

Lenis smooth scrolling is working.

Responsive behavior is working.

The purpose of this phase is NOT to redesign the website.

The purpose of this phase is to completely transform the existing Harroway website into the Future City brand while preserving the current layouts, interactions, and animation system.

This phase establishes the project identity before the immersive redesign begins.

---

# IMPORTANT

This is NOT a UI redesign.

This is NOT a component rewrite.

This is NOT an animation rewrite.

Do NOT change the architecture.

Do NOT modify the component hierarchy unnecessarily.

Do NOT remove existing animations.

Do NOT replace GSAP.

Do NOT replace Lenis.

Do NOT modify spacing unless content absolutely requires it.

The website should continue to function exactly as it does now.

Only the branding, content, imagery, navigation, and metadata should change.
