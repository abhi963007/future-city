# Future City — Project Context

## Overview

This project was originally a premium Webflow template called **Harroway**, designed for luxury real estate agencies.

The project has already been successfully migrated to a modern React architecture using:

- React 19
- TypeScript
- Vite
- GSAP
- ScrollTrigger
- SplitText
- Lenis
- React Router
- React Helmet
- Modern reusable component architecture

The migration is complete.

The React architecture is stable.

The animation system is stable.

The responsive behavior is stable.

The objective is NOT to redesign the architecture anymore.

The project now enters the branding and experience transformation phase.

Do NOT rebuild the project.
